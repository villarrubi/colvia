Alejandro Villarrubia

Arquitectura de software y sistemas a medida.

Diseña la base técnica de cada proyecto para que el software responda bien hoy y siga siendo fácil de mantener con el paso del tiempo. Ha desarrollado desde herramientas de gestión y aplicaciones web hasta sistemas de cálculo y planificación con alta exigencia técnica.
